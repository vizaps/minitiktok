Mini TikTok (Projeto Simples)

Projeto simples inspirado no TikTok/Reels, desenvolvido para praticar conceitos básicos de desenvolvimento web.

Sobre o projeto
A aplicação permite visualizar um conteúdo estilo feed, com funcionalidades básicas como troca de imagem e interação por curtidas.

Funcionalidades
- Alteração de imagens no feed
- Sistema simples de curtidas
- Interface básica inspirada em redes sociais

Tecnologias utilizadas
- HTML (estrutura da página)
- CSS (estilização)
- JavaScript (interatividade e lógica)

Objetivo
Praticar conceitos iniciais de desenvolvimento web, manipulando elementos na tela e criando interações com JavaScript.

Status
Projeto simples para aprendizado (iniciante)
